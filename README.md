# 30 days, 30 projects

One small, self-contained project per day. Pick any language you like for each — mixing languages across days is encouraged, since it keeps things interesting and gives your critter's "variety" stat something to chew on. Each one is scoped to be buildable in a single sitting.

## Week 1 — Command line and scripts

- [ ] **Day 1** — A CLI to-do list (add, list, complete, delete tasks, saved to a file)
- [ ] **Day 2** — A password generator with configurable length and character sets
- [ ] **Day 3** — A file organizer that sorts a messy folder into subfolders by file type
- [ ] **Day 4** — A unit converter (temperature, distance, currency — pick one or all three)
- [ ] **Day 5** — A simple Markdown-to-HTML converter
- [ ] **Day 6** — A CLI pomodoro timer with desktop notifications
- [ ] **Day 7** — A duplicate file finder for a folder tree

## Week 2 — Web and APIs

- [ ] **Day 8** — A single-page weather app using a free public weather API
- [ ] **Day 9** — A URL shortener with a local database
- [ ] **Day 10** — A quote-of-the-day widget that pulls from a public quotes API
- [ ] **Day 11** — A personal link/bookmark manager with tags and search
- [ ] **Day 12** — A simple REST API for a notes app (CRUD endpoints, no frontend needed)
- [ ] **Day 13** — A GitHub profile viewer — enter a username, show their public repos and stats
- [ ] **Day 14** — A markdown-based blog generator that turns a folder of `.md` files into static HTML pages

## Week 3 — Games and interactive

- [ ] **Day 15** — Tic-tac-toe with a simple AI opponent
- [ ] **Day 16** — A number-guessing game with difficulty levels
- [ ] **Day 17** — Conway's Game of Life, rendered in a terminal or canvas
- [ ] **Day 18** — A hangman or word-guessing game with a word list file
- [ ] **Day 19** — A simple text adventure with rooms and inventory
- [ ] **Day 20** — A memory-matching card game (grid of flip tiles)
- [ ] **Day 21** — A basic snake game

## Week 4 — Data, automation, and stretch projects

- [ ] **Day 22** — A CSV analyzer that summarizes a dataset (averages, min/max, counts)
- [ ] **Day 23** — A script that scrapes and summarizes headlines from a news site's RSS feed
- [ ] **Day 24** — A budget tracker that logs expenses and shows spending by category
- [ ] **Day 25** — A Discord or Slack bot that responds to a couple of simple commands
- [ ] **Day 26** — A Chrome extension that does one small useful thing (e.g. hides a page element, saves selected text)
- [ ] **Day 27** — A basic Markov-chain text generator trained on a text file
- [ ] **Day 28** — A habit tracker with a simple streak calendar (great pairing with the critter's own logic)
- [ ] **Day 29** — A recipe box app — store, tag, and search recipes locally
- [ ] **Day 30** — Pick your favorite project from the month and add one real feature you didn't have time for

---

**Tip:** each project is meant to fit in a day, not be perfect. Ship something working, commit it, move on — polish is what Day 30 is for.
